# Introducción a CSS: El diseño detrás de cada gran sitio

Si **HTML** es el esqueleto de una página web —como la alineación inicial de un equipo en el campo—, entonces **CSS** es su *estética, ritmo y personalidad*: los colores del uniforme, la intensidad del juego, la claridad de las transiciones.

**CSS** (*Cascading Style Sheets*, o *Hojas de Estilo en Cascada*) es el lenguaje que permite **dar estilo y diseño** a los documentos HTML. Define cómo se ven los elementos: colores, tipografías, espaciado, disposición en pantalla… ¡hasta animaciones de goles o gráficos tácticos en movimiento!

---

# 📜 ¿Por qué "Cascading"?

El término *cascading* (en cascada) se refiere a la forma en que las reglas de estilo **se heredan y superponen**, como órdenes tácticas que se aplican desde el cuerpo técnico hasta los jugadores en el campo:

- Un estilo definido para todo el `<body>` afecta a *todos* los elementos internos…  
- …pero una regla específica para un `<h1>` puede *sobrescribirla* si es más específica o está más cerca del elemento.

Ejemplo básico:

```css
body {
  font-family: 'Roboto', sans-serif;
  background-color: #0a2e5a; /* Azul fondo estadio */
  color: #ffffff;            /* Letras blancas, como las camisetas del Madrid */
}

h1 {
  color: #ffcc00; /* Amarillo: ¡el brillo de un golazo! */
  text-shadow: 1px 1px 3px rgba(0,0,0,0.5);
}
```
